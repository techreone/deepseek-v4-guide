# DeepSeek-V4.1-Flash-1017（2026-10-17）

## 一句话
DeepSeek 于 **2026-10-17** 发布 **DeepSeek-V4.1-Flash-1017** —— V4.1-Flash 的一个 post-training 增量 checkpoint（**架构、参数、价格全不变**），同日把自研 **Search / Fetch API 对外开放**；官方称之为 "a Pareto improvement in performance and cost"（性能涨、成本不涨）。

## 命名与 API（关键，防误写）
- 四位后缀 **1017 = 发布日期 10 月 17 日**（公司快照命名惯例，非版本号）
- **API 模型名不变，仍是 `deepseek-flash`** → 现有集成**零改动**自动切到 1017（官方原话：live on website, app, and API）
- 旧名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` **仍被接受**，同样由 1017 服务、按 Flash 价计费
- 官方要求：**DeepSeek Harness ≥ v0.2.1-rc.1**（该 checkpoint 专门为它调优）；另点名 **Tencent CodeBuddy / WorkBuddy**
- 官方文档/pricing 页 MODEL VERSION 字段现写 **DeepSeek-V4.1-Flash-1017**

## 架构（与 9 月版完全一致，无变化）
- **Causal Encoder–Decoder (CED)**：40 层 = 20 层 causal encoder + 20 层 decoder
- **552B 主干 + 196B Engram**（HF 显示 763B 参数）
- 激活：**prefill 8B / decode 16B**
- 上下文 **1M**（1,048,576）；API 最大输出 **384K**；并发上限 **2500**
- 原生视觉（text + image in）；thinking 默认开
- KV 缓存：FP4 main KV **890 bytes/token**；SWA Bounded Replay
- 官方 model card 引用标题：**"DeepSeek-V4.1-Flash: Pushing the Limits of KV Cache Compression"**

## 训练方法（这次唯一真正的变化）
- **Reinforcement learning with self-feedback**（自反馈强化学习），目标从"单轮答得好"改成"**端到端把项目做出来**"
- 官方演示 4 个项目：**故宫 3D 重建、浏览器赛车游戏、Godot 复刻 Portal 2、Valley of Ages（史前→现代演化 3D 场景）**
- 官方营销词 **"Wish-Driven Programming Made Real"**（愿望驱动编程）
- 行为变化：**输出更短、任务完成更快**（Pareto 的另一半）

## 价格（无变化，仍是 V4.1-Flash 价）

| deepseek-flash | Peak | Off-peak |
|---|---|---|
| 输入 cache hit | $0.006 | $0.003 |
| 输入 cache miss | $0.30 | $0.15 |
| 输出 | $1.20 | $0.60 |

- Off-peak = Peak 一半；**Peak 时段 01:00–04:00 与 06:00–10:00 UTC 周一至周五**（中国法定节假日除外），其余全算 off-peak
- 真实成本：官方端点 **cache 命中率 91.5%**，OpenRouter 加权后**实际输入价约 $0.017/M**；OpenCode 侧观测 cache ratio **97%**
- 成本下降的真实来源 = **输出变短**（同价下每任务更便宜）

## 同日开放：Search / Fetch API（新，重要）
- 端点：`POST https://api.deepseek.com/v1/tools/search` 与 `POST .../v1/tools/fetch`
- 底层是 DeepSeek **自研搜索引擎**（官方称日均服务数亿次请求、索引数千亿网页）
- **$0.75 / 1,000 次成功请求**（两个端点各自计费；失败/空结果不计费）；人民币表述 **CNY 5 / 1,000 次**
- QPS 限制：Search 5 / Fetch 5（账户级，各自独立）
- Search 支持算子：`site:` / `-site:` / `-` / `"-"` / `"..."` / `lang:` / `after:` / `before:`；结果带 `rerank_score`(0–3) 与 `authority`(0–4)
- Fetch 把任意 URL 转 Markdown 返回
- **免费窗口**：经 DeepSeek Harness / Claude Code / Codex 的 server-side 工具调用，**截至 2026-10-31 16:00 UTC 免费**（另有来源写 11 月 1 日）

## 开源权重
- **MIT**，HF `deepseek-ai/DeepSeek-V4.1-Flash-1017` + ModelScope，发布当天上线
- 无 Jinja chat template：官方给 `encoding/encoding.py` 参考实现 + `deepseek-recipe`（Rust，带 Python 绑定）
- 推荐采样：**temperature 1.0、top_p 1.0**、max_tokens ≥ 256K
- 社区量化：**Baekpica/DeepSeek-V4.1-Flash-1017-VQ-GGUF** 于发布当天转换完成 —— 510GB 官方 checkpoint → **~113.6 GB 基础 GGUF**（含模型自带三塔 MTP drafter + ~1GB vision sidecar + 1017 Engram 表），面向单台 **128GB DGX Spark**；1,000 tensors / 113,556,639,424 bytes，loader 校验 `bind: slots=1000 bound=1000 required-missing=0`
- 官方 checkpoint 规模：~511 GB（9 月版口径）；自托管仍属数百 GB 级工程
