### What Is DeepSeek R2 Expected to Be?

DeepSeek R2 is generally discussed as a possible successor to DeepSeek R1, the reasoning-focused model family that helped bring DeepSeek wider global attention. However, until DeepSeek publishes an official R2 announcement, model card, API model ID, repository, or pricing listing, R2 should be treated as an unconfirmed future release.

Reputable reporting has described R2 as a model expected to improve coding and reasoning in languages beyond English. Those are reported goals, not official product specifications. Users should not treat feature expectations, benchmarks, release windows, or leaked claims as confirmed.

### What Has Been Reported About DeepSeek R2?

Reuters reported in June 2025 that DeepSeek had not yet determined the timing of R2’s release because CEO Liang Wenfeng was not satisfied with the model’s performance, citing a report by The Information. Reuters also wrote that R2 had been planned as a successor to R1 and was expected to improve coding and multilingual reasoning.

Reuters later reported, citing Financial Times reporting, that a DeepSeek new-model launch had been delayed after issues with training on Huawei chips. This should be treated as reported information, not as an official DeepSeek statement or confirmed R2 launch detail.

TechNode reported, citing a person familiar with the company’s plans, that DeepSeek denied renewed speculation about an August R2 launch window. The report also said DeepSeek had not announced an official release date or technical details for R2.

### DeepSeek R2 vs R1, R1-0528 and V4

DeepSeek R1 is the known reasoning-focused model family. DeepSeek-R1-0528 is an update that users may confuse with R2 because of the similar naming pattern and release-date speculation.

DeepSeek V4 is a different official model line currently documented by DeepSeek. The official V4 Preview release describes V4-Pro and V4-Flash, and the API docs list V4 model IDs. R2 should not be assumed to be the same as V4 unless DeepSeek says so in official sources.
