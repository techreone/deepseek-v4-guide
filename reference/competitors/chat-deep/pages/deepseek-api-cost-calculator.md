## 正文
Estimate DeepSeek API costs before you build. This calculator helps you forecast per-request, daily, monthly, and yearly spend for both deepseek-v4-flash and deepseek-v4-pro using current DeepSeek V4 API pricing, including cache-hit discounts.

V4-Flash and V4-Pro share a 1M context window and 384K max output, but pricing differs sharply: V4-Flash is the low-cost workhorse, while V4-Pro targets the hardest reasoning, math, and code workloads. Use the calculator to compare workloads before you ship.
